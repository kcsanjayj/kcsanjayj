## Why work with me

A wrong model is normal. A system that is wrong **and looks fine** is the real risk.

I build LLM systems that **count their retries, label partial results, cap their budgets, and say what their evals don't prove.** You always know what happened, even when it goes wrong.

## What I've built

### 🦀 [rapTOR](https://github.com/kcsanjayj/rapTOR) · Agents that fail honestly
Plans work as a validated graph, runs tasks in parallel, and has a critic review and repair weak output. Runs offline with fault injection, so recovery is testable.
- 63 Rust tests and 26 deterministic end-to-end evals, in CI on Ubuntu and Windows
- Rewrote it after a self-review found 8 defects; each now has a regression test

### 📚 [Spaghetti](https://github.com/kcsanjayj/Spaghetti) · Private document Q&A
Ask questions over PDF, DOCX and text with a local model. Citations included, no cloud, no API keys. [Live UI](https://spaghetti.kcsanjayj.workers.dev)
- Relevance threshold chosen by ablation: abstention 0.8 → 1.0, no retrieval loss
- Rust core with a Python twin, 87 tests, zero axe-core accessibility violations

### 🧠 [TinyGPT-X](https://github.com/kcsanjayj/TinyGPT-X) · A language model from scratch
13.9M-parameter transformer in PyTorch, trained in about 11 minutes on a 6 GB laptop GPU. Perplexity 6.05 on TinyStories. [On Hugging Face](https://huggingface.co/kcsanjayj/TinyGPT-X), with export parity verified.
